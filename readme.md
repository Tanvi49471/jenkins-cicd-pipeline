# Grand Palace – Hotel Management Website

## Project Overview

Grand Palace is a responsive hotel website developed using HTML and CSS. It provides an attractive interface for exploring hotel rooms, services and booking information.

## Technologies Used

- HTML5
- CSS3
- Git and GitHub
- Jenkins
- Groovy
- Linux

## Features

- Modern hotel homepage
- Responsive navigation bar
- Hotel room listing
- Room pricing information
- Booking information section
- Hotel services section
- Contact information
- Responsive design for mobile devices

## Project Structure

```text
jenkins-cicd-pipeline/
├── Jenkinsfile
├── index.html
├── style.css
└── README.md
```

## CI/CD Integration

This project uses Jenkins to automate the application pipeline.

Planned pipeline stages:

1. Checkout source code from GitHub.
2. Build and validate application files.
3. Test project file availability.
4. Deploy the website to a web server.

## How to Run

1. Clone the GitHub repository.
2. Open the project folder.
3. Open index.html in a web browser.
